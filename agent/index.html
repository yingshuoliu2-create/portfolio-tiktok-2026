具体实现

01

任务依赖与质量检查

用 TypeScript 定义 15 个阶段的依赖、输入、交付物与检查项。上游未通过时，下游标为 blocked，并提供问题诊断。

02

Provider 接口与运行记录

定义图像、动态、配音、音效、渲染五类服务接口。通过 API 记录任务参数、结果和执行状态；接口定义不等于外部服务已经接通。

03

人工确认与回退指向

用角色确认与内容审阅控制放行；用 retryTo 指出失败后应回到的制作阶段，保留人工处理和复核。
